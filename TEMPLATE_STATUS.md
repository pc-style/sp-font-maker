# Mathematical Handwriting Template

## Template Status

The current templates (template.svg, template.png, template.pdf) are inherited from the sitelen pona font maker.

The grid structure remains 20 columns × 9 rows = 180 cells.

## Temporary Workaround

Until new templates are created, users can:
1. Use the existing sitelen pona template
2. Fill in cells from left to right, top to bottom with mathematical symbols in this order:
   - Row 0: A-T
   - Row 1: U-Z, a-m
   - Row 2: n-z, 0-7
   - Row 3: 8-9, Greek uppercase (Α-Σ)
   - Row 4: Greek uppercase (Τ-Ω), Greek lowercase (α-ξ)
   - Row 5: Greek lowercase (ο-ω), basic operators
   - Row 6: Mathematical operators and set symbols
   - Row 7: Arrows and logic symbols
   - Row 8: Brackets, punctuation, and special characters

## Creating the New Template

The template should be created as:
- SVG file for editing
- PDF for printing
- PNG files at various resolutions (2px, 4px, 6px, 8px, 10px, 12px, 16px for testing)

Each cell should clearly label the expected symbol with both its name and Unicode character.
